# Himanshu Rajput | Banking Business Analysis Portfolio

Independent portfolio case studies demonstrating business analysis documentation for banking workflows. The materials are scenario-based design exercises, not banking employment, client engagements, production implementations, or executed UAT. Proposed thresholds and service levels are requirements for the scenarios, not achieved results.

## Case studies

### Project 01 | Digital account opening

Retail savings onboarding requirements across document capture, OCR, KYC/AML screening, CBS account creation, notifications, exception handling, and UAT scenario design.

### Project 02 | Loan origination enhancement

LOS co-applicant user stories, combined income and DTI assessment, credit bureau checks, exception handling, and underwriter decision workflows.

### Projects 03-04 | Regulatory compliance

Customer risk classification, Enhanced Due Diligence, fraud monitoring, audit logging, compliance reporting, and related UAT scenarios.

## Artifact index

Each project folder contains readable Markdown versions of the supplied requirements and test-design artifacts. Sample names and identifier values have been anonymized. Project 01 uses a fictional US retail bank scenario.

- [Project 03: Regulatory compliance](Project_03/regulatory-compliance-implementation.md) - CDD/EDD, fraud monitoring, audit, and reporting requirements.

## Review notes

- UAT materials describe planned test scenarios and cases; blank status fields in the source were not represented as completed execution.
- Numeric performance values in the documents are proposed requirements or targets, not measured outcomes.
- The case-study artifacts show analysis deliverables and domain knowledge, not professional banking experience.
